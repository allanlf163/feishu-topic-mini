# 标准工作流

这份文档说明本 skill 每次处理 AI 配图任务时应该怎么走流程。完整 prompt、文字、风格锁、重试和记录规范见 `imagegen-spec.md`。

## 任务边界

本 skill 只处理 AI 生图配图：

- 公众号头图和正文插图。
- 小红书封面和图文轮播。
- 文章正文插图。
- 通用封面图。
- 笔记本风格或其他自定义风格配图。

本 skill 不处理：

- 网络搜图。
- 候选图片下载。
- 版权授权判断。
- HTML/CSS/SVG/canvas/PIL/截图模板成图。
- 后期修图、抠图、擦字、代码补字。

## 每次任务的执行顺序

1. 读 `memory.md`。
2. 判断用户当前想要的是哪个入口：
   - `/AI生图`
   - `/公众号配图`
   - `/小红书配图`
   - `/AI文章插图`
   - `/AI封面图`
   - `/笔记本风格`
3. 判断平台：公众号、小红书、通用文章，或用户自定义用途。
4. 判断产物：头图、正文图、封面、单张图、轮播图、多张插图。
5. 判断比例和尺寸：
   - 公众号头图：21:9，建议 2100x900。
   - 公众号正文图：16:9，建议 1920x1080。
   - 小红书：3:4，建议 1080x1440。
   - 通用图：按用户用途判断；不明确时先问。
6. 判断风格：
   - 用户指定风格则按指定。
   - 用户说 `/笔记本风格`，读取 `custom-styles.md`。
   - 用户未指定时，根据平台和内容选择 `prompt-presets.md` 中的预设。
7. 先给配图规划，等用户确认后再生图。
8. 生成前写清楚最终 prompt。
9. 调用 `image_gen`。
10. 按 QA 清单检查。
11. 输出成功图和简短说明。

## 路由判定优先级

当用户输入里同时出现平台、用途和风格时，按这个顺序判断：

1. 显式平台或产物命令优先：`/公众号配图`、`/小红书配图`、`/AI封面图`。
2. 明确用途其次：头图、正文插图、小红书封面、轮播、文章插图。
3. 风格命令最后：`/笔记本风格` 只决定视觉气质，不决定比例。
4. 长期记忆只做辅助，不覆盖用户本次明确要求。

示例：

- `/小红书配图 笔记本风格`：平台是小红书，比例是 3:4，风格是笔记本。
- `/公众号配图 笔记本风格`：平台是公众号，头图仍是 21:9，正文图仍是 16:9，风格是笔记本。
- `/AI封面图 笔记本风格`：产物是封面，风格是笔记本；平台不明确时先推断或询问。
- `/笔记本风格 帮我做一张封面`：平台不明确时，先根据上下文推断；无法推断就问“用于公众号还是小红书？”。

## 什么时候需要先确认

下面这些情况默认必须先给规划，不要直接生图：

- 公众号文章配图。
- 小红书轮播图。
- 文章转图文卡片。
- 多张图同一组风格。
- 图片里需要出现较多中文文字。
- 用户还没明确平台或数量。

用户明确说这些话时，可以直接生成：

- “直接生成”
- “不用确认”
- “先出一版”
- “你自己决定”

即使直接生成，也要先在内部完成平台判断、文字规划和 prompt 组织。

## 配图规划表

规划表建议使用：

| 图片 | 平台 | 使用位置 | 目标 | 画面文字 | 视觉方案 | 尺寸 |
|---|---|---|---|---|---|---|

填写要求：

- `图片`：如“头图”“正文图 1”“小红书封面”“第 2 页”。
- `平台`：公众号、小红书、通用。
- `使用位置`：文章顶部、正文某段后、小红书第 1 页等。
- `目标`：这张图解决什么阅读问题。
- `画面文字`：写出图片上会出现的具体短句。
- `视觉方案`：构图、元素、风格、色彩和信息层级。
- `尺寸`：写清比例和建议像素。

## 单图任务

适用于 `/AI生图`、单张封面、单张正文插图。

流程：

1. 确认用途和平台。
2. 选择比例。
3. 规划可见文字和画面结构。
4. 写 prompt。
5. 调用 `image_gen`。
6. QA 后展示。

## 多图任务

适用于小红书轮播、一篇文章多张插图、一组系列图。

流程：

1. 先做内容分析。
2. 拆出每张图的目标和信息点。
3. 建立统一风格锁。
4. 输出完整规划表。
5. 用户确认后逐张生成。
6. 每张图都延续同一风格锁。
7. 任何一张风格漂移，都应重新 prompt 后重生成。

## 文章拆图流程

用户给一篇文章并要求配图或转图文时，不要直接按段落机械切图。先做内容拆解：

1. 提炼文章主结论。
2. 找出读者最关心的痛点或收益。
3. 拆出知识点、步骤、误区、对比、案例、清单。
4. 判断哪些内容适合画成图，哪些内容留在正文即可。
5. 给每张图设置一个明确任务：吸引、解释、对比、总结、行动提醒。
6. 小红书轮播按知识点拆页；公众号正文图按文章阅读节点插入。

如果文章内容很多，优先保留会改变读者行动的信息：判断标准、步骤顺序、避坑、例外、话术、检查清单。

如果文章内容很少，不要硬凑多页；可以建议生成单张封面或单张知识卡。

## 长期记忆使用方式

读记忆时重点看：

- 用户业务和受众。
- 常发平台。
- 喜欢或排斥的风格。
- 文字密度偏好。
- 是否偏好笔记本风格、手写风格、编辑部风格等。

写记忆时只写稳定信息：

- 用户明确说“记住”。
- 用户说“我以后都喜欢这样”。
- 同一偏好重复出现多次。

不要写入：

- 一次性主题。
- 临时标题。
- 私密链接。
- API key、账号、密码。
- 客户隐私或内部资料。
