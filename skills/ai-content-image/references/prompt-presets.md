# Prompt 预设库

这里的预设用于减少 AI 生图的随机性。预设不是模板，不要求每次一模一样；它们提供平台感、构图语言、材质和文字密度方向。

## 1. 通用构图原则

### 平台优先

先判断图片发在哪里，再决定比例、文字密度和视觉语言。

- 公众号：成熟、克制、编辑部感。
- 小红书：标题强、信息清楚、收藏价值高。
- 通用文章：服务内容理解，不抢正文。

### 内容优先

图片首先要帮读者理解内容，其次才是好看。

不要生成只有氛围、没有信息的空图，除非用户明确要背景图或氛围图。

### 文案优先

先规划图片上的标题、标签、步骤、注释，再写 prompt。

不要在 prompt 里只写“生成一张高级感图片”，这会导致随机。

### 真实材质

优先使用读者熟悉的材质：

- 纸张。
- 笔记本。
- 桌面。
- 白板。
- 屏幕。
- 文件。
- 便签。
- 卡片。
- 书页。

真实材质比抽象光效更稳定，也更适合内容配图。

### 中文阅读流

中文标题和标签要符合中文阅读习惯：

- 标题醒目。
- 模块分组。
- 短句表达。
- 不要英文海报式排版压过中文。

### 系列风格锁

多图任务必须保持：

- 同一字体或笔迹。
- 同一标题层级。
- 同一标签样式。
- 同一色彩系统。
- 同一材质。
- 同一构图语言。

## 2. 内置风格：笔记本风格

入口：`/笔记本风格`

适合：

- 小红书知识笔记。
- 课程笔记。
- 文章总结。
- 复盘清单。
- 方法论步骤。
- 公众号正文解释图。
- 通用干货图。

视觉方向：

- 真实螺旋笔记本或打开的笔记本页面。
- 暖白纸张。
- 轻微桌面环境，比如键盘边缘、笔、便签、纸张阴影。
- 黑色手写中文为主。
- 红色用于标题、圈号、重点、下划线和提醒。
- 淡黄色荧光笔用于小标题或关键词。
- 手绘方框、箭头、括号、流程线、勾选框。
- 像真实学习笔记，不像扁平模板。

文字规则：

- 中文短句。
- 模块化。
- 一页一个核心目标。
- 不复制长段原文。
- 不要只有几个关键词。
- 不要挤成小字。

小红书适配：

- 3:4，1080x1440。
- 可以中高信息密度。
- 封面标题要非常清楚。
- 内容页像可收藏的手写学习笔记。

公众号适配：

- 头图仍用 21:9，保持呼吸感。
- 正文图用 16:9，解释一个概念或流程。
- 笔记本元素作为视觉隐喻，不要把头图塞得太满。

Prompt 关键短语：

```text
笔记本风格，真实螺旋笔记本页面，暖白纸张，桌面轻微阴影，黑色手写中文，红色重点标记，淡黄色荧光笔标签，手绘方框和箭头，像真实课程笔记
```

## 3. 公众号预设

### wechat-editorial-cover：编辑部专题头图

适合：

- 公众号头图。
- 长文封面。
- 专题文章。
- 观点文章。

视觉方向：

- 成熟编辑部封面。
- 横版构图。
- 一个具象主视觉。
- 清楚标题安全区。
- 色彩克制。
- 不像广告。

常用元素：

- 桌面、文件、书、电脑、笔记。
- 城市、办公室、会议室。
- 象征性物件。
- 暗示文章主题的场景。

### wechat-longform-header：长文观点头图

适合：

- 深度思考。
- 行业观察。
- 商业复盘。
- 个人成长长文。

视觉方向：

- 安静。
- 克制。
- 留白。
- 具象隐喻。
- 文字少。

### wechat-explanatory-illustration：正文解释图

适合：

- 概念解释。
- 关系说明。
- 机制拆解。
- 方法总结。

视觉方向：

- 简洁图解。
- 2-5 个节点。
- 有标题和短标签。
- 帮读者理解，不做装饰。

### wechat-method-map：方法框架图

适合：

- SOP。
- 步骤。
- 框架。
- 决策路径。

视觉方向：

- 3-6 个步骤节点。
- 线条连接。
- 轻量图标。
- 短中文标签。

## 4. 小红书预设

### xhs-knowledge-card：知识卡

适合：

- 概念解释。
- 认知总结。
- 观点卡。

视觉方向：

- 竖版卡片。
- 强标题区。
- 3-5 个结构模块。
- 少量图标或物件隐喻。
- 温和但有重点的配色。

### xhs-material-notes：资料笔记

适合：

- 资料整理。
- 课程笔记。
- 清单资源。
- 学习卡。

视觉方向：

- 纸张、便签、荧光笔、笔记本。
- 信息密度中等偏高。
- 看起来像值得收藏的一页资料。

### xhs-method-checklist：方法清单

适合：

- 方法步骤。
- SOP。
- 操作流程。
- 避坑清单。

视觉方向：

- 编号步骤。
- 勾选框。
- 流程箭头。
- 行动感强。

### xhs-case-breakdown：案例拆解

适合：

- 案例复盘。
- 爆款拆解。
- 错误分析。
- 前后对比。

视觉方向：

- 对比栏。
- 批注线。
- 结论框。
- “案例 -> 发现 -> 可复用动作”的结构。

### xhs-product-seeding：产品种草

适合：

- 课程。
- 资料包。
- 工具。
- 服务。

视觉方向：

- 产品主视觉。
- 使用场景。
- 收益标签。
- 干净可信。
- 不要广告大字报。

### xhs-emotional-resonance：情绪共鸣

适合：

- 个人成长。
- 焦虑缓解。
- 自我复盘。
- 共鸣型内容。

视觉方向：

- 柔和真实场景。
- 日记感。
- 文字少但命中情绪。
- 不要过度煽情。

## 5. 通用预设

### general-editorial-visual：通用编辑视觉

适合：

- 平台不明确。
- 通用封面。
- 文章配图。

视觉方向：

- 高质量编辑图。
- 一个清晰焦点。
- 与内容相关的物件或场景。
- 色彩克制。
- 可选短标题。
