# 小红书配图规范

用于 `/小红书配图`、小红书场景下的 `/AI封面图`，以及 `/笔记本风格` 生成小红书图文时。

## 1. 默认产物

小红书默认规格：

- 比例：3:4。
- 建议尺寸：1080x1440。
- 第一张是封面。
- 后续是内容页。
- 短笔记通常 3-6 张。
- 文章转图文通常 6-12 张。
- 上限建议 18 张。

不要为了强行压缩到 5-7 张而丢掉关键知识点。内容多时可以增加页数；内容少时不要硬凑页数。

文件名建议：

```text
xhs-01-cover.png
xhs-02-page.png
xhs-03-page.png
...
xhs-18-page.png
```

## 2. 小红书主要图文类型

### 知识卡

适合：

- 概念解释。
- 认知总结。
- 观点提炼。
- 方法框架。

特点：

- 标题强。
- 结构清楚。
- 3-5 个模块。
- 可收藏。

### 资料笔记

适合：

- 课程笔记。
- 学习资料。
- 资源整理。
- 清单。

特点：

- 纸张、笔记、便签、高亮等视觉元素。
- 信息密度可以稍高。
- 像一页真实学习笔记。

### 方法论清单

适合：

- SOP。
- 操作步骤。
- 流程。
- 避坑。

特点：

- 编号。
- 步骤。
- 勾选框。
- 从上到下或从左到右的行动路径。

### 案例拆解

适合：

- 案例复盘。
- 前后对比。
- 失败原因分析。
- 爆款拆解。

特点：

- 对比栏。
- 批注。
- 结论框。
- “案例 -> 发现 -> 可复用动作”的结构。

### 产品种草

适合：

- 课程。
- 资料包。
- 工具。
- 服务。
- 虚拟产品。

特点：

- 产品主视觉。
- 使用场景。
- 收益标签。
- 不要过度广告化。

### 情绪共鸣

适合：

- 成长感悟。
- 焦虑缓解。
- 私域故事。
- 个人经历。

特点：

- 画面柔和。
- 文字少而击中情绪。
- 不要过度煽情或廉价鸡汤。

## 3. 小红书封面规则

封面必须解决“让人停下来”的问题。

封面应包含：

- 一个手机缩略图可读的主标题。
- 一个明确的利益点、痛点或好奇点。
- 视觉焦点。
- 适合小红书信息流的强层级。

封面不应：

- 只是一张漂亮背景。
- 标题太小。
- 标题太长。
- 画面没有重点。
- 像公众号头图横裁。
- 像 PPT 首页。

常用封面标题方向：

- 痛点型：`为什么你做图总是没人看`
- 结果型：`3 步做出可收藏笔记`
- 避坑型：`新手最容易踩的 5 个坑`
- 清单型：`发布前检查这 7 项`
- 对比型：`普通配图 vs 可收藏配图`

标题要真实，不要夸大承诺。不要为了点击制造焦虑或虚假收益。

## 4. 小红书内容页规则

内容页必须有实际信息价值。

一页通常只讲一个核心点：

- 一个判断。
- 一个步骤。
- 一个误区。
- 一个对比。
- 一个清单。
- 一个案例发现。

内容页可以中高信息密度，但必须：

- 标题、模块、正文分层清楚。
- 文字短句化。
- 不堆长段落。
- 重点可一眼扫到。
- 手机上能看清。

如果页面只有标题加几个孤立关键词，就太空；如果满屏小字读不清，就太挤。两种都需要重做。

## 5. 小红书文字策略

封面：

- 主标题短、有钩子。
- 可以加副标题或 3 个短标签。
- 标题必须大。

内容页：

- 页面标题清楚。
- 模块标题短。
- 每个模块配一句解释。
- 清单项尽量短句。
- 重要词用颜色、圈号、下划线或高亮强调。

不建议：

- 长段原文复制。
- 一页塞完整文章。
- 全部文字都用同样大小。
- 标题和正文层级不分。

## 6. 小红书比例要求

prompt 必须写清：

```text
3:4 竖图，1080x1440，小红书图文比例
```

如果生成结果明显是 2:3、过窄长图或非小红书比例，要记录失败并重新生成。

## 7. 小红书系列一致性

同一组图必须统一：

- 字体或手写气质。
- 标题层级。
- 标签形状。
- 色彩系统。
- 背景材质。
- 插画或真实材质风格。
- 模块样式。

封面可以更强、更醒目；内容页要延续风格，但不要每页都像封面。

## 8. 小红书生成流程

1. 读取文章、主题或用户输入。
2. 判断图文类型：知识卡、资料笔记、方法论清单、案例拆解、产品种草、情绪共鸣。
3. 提炼封面钩子。
4. 拆分内容页，每页一个核心点。
5. 建立风格锁。
6. 输出规划表，包含每页可见文字。
7. 用户确认。
8. 逐张写 prompt 并调用 `image_gen`。
9. QA 比例、文字、信息密度、风格一致性。
10. 展示成功图。

## 9. 文章转小红书轮播拆页

文章转轮播时，推荐页型：

1. 封面：主题钩子和结果承诺。
2. 总结页：先给核心结论。
3. 判断页：告诉读者什么时候适用。
4. 方法页：拆步骤。
5. 避坑页：讲常见错误。
6. 案例页：用一个简化案例说明。
7. 清单页：给读者可执行检查项。
8. 结尾页：总结和下一步。

不是每篇文章都要 8 页。按内容需要取舍：

- 内容短：封面 + 2-3 张内容页即可。
- 内容中等：封面 + 4-6 张内容页。
- 内容很长：封面 + 多张内容页，最多建议 18 张。

每页都要能回答一个问题：读者看完这一页，知道了什么、会做什么、能避免什么？

## 10. 小红书 prompt 示例

```text
任务：/小红书配图
平台：小红书
用途：第 2 页内容卡
尺寸：3:4 竖图，1080x1440
图文类型：方法论清单
页面目标：让新手知道复盘课程时先看哪三个指标
画面文字：
- 页面标题：先看这 3 个指标
- 模块 1：完课率 -> 内容有没有被听完
- 模块 2：互动率 -> 学员有没有真的参与
- 模块 3：转化率 -> 结果有没有带来下一步
- 底部提醒：别只看销售额，先看学习行为
视觉方案：
小红书知识卡，白底纸张质感，三个竖向模块，红色圈号，浅黄色重点高亮，少量手绘箭头。
风格锁：
延续全组白底纸张、红色重点、黄色高亮、黑色清晰中文标题和模块卡片样式。
负向约束：
不要 PPT，不要广告海报，不要长段落，不要小字挤满，不要水印，不要随机人物。
版本：v1
```
